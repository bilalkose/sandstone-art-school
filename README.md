# Sandstone Art School

Website for Sandstone Art School, children's art classes in Worksop and Sheffield.
A trading name of Infinite Art Ltd.

## Pages

- `index.html` – home page
- `curriculum.html` – the six-theme curriculum and Portfolio Studio
- `worksop.html`, `sheffield.html` – branch pages with timetables and trial booking forms
- `thanks.html` – shown after a booking form is sent

## Booking forms

The trial booking forms use Netlify Forms (form name `trial-booking`).
Submissions appear in the Netlify dashboard under **Forms**.
